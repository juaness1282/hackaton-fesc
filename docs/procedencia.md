# Procedencia de esta reconstrucción

Este repositorio comienza con el kit original proporcionado por la universidad. La implementación se reconstruye en esta carpeta con asistencia de IA después de una solución previa desarrollada en otra carpeta. No se importa el código de esa solución ni su historial. Los commits registran el trabajo realizado a partir de esta reconstrucción con sus fechas reales; no representan contribuciones de un segundo integrante ni sesiones anteriores.
