# Guion de pitch de hasta 60 segundos

0–12 s: El sistema antiguo de una caja comparte su base entre varias aplicaciones. Cambiar el esquema o detener la base puede interrumpir consultas y perder retiros.

12–28 s: Construimos un gateway con adapter y modelo canónico. Portal, Subsidios y el consumidor móvil usan HTTP y tokens, mientras Educación conserva su código original.

28–45 s: Los retiros se registran con comprobantes idempotentes y una cola persistente. Probamos una caída, reiniciamos gateway y recuperamos la solicitud con exactamente un movimiento.

45–58 s: El contrato se mantuvo al renombrar el esquema. El rollback permitió registrar por Subsidios con gateway apagado. Quince pruebas de integración pasaron incluso con una base vacía.
